# FormuTech

Sitio web B2B de **FormuTech**, empresa colombiana de formulación y fabricación de lubricantes industriales y especialidades químicas. Posiciona a la compañía como ingeniería aplicada a fluidos: entender la operación, formular o recomendar, y acompañar técnicamente.

Tagline: **INGENIERÍA EN CADA GOTA**. Principio: *No prometemos más. Demostramos mejor.*

## En Vercel

Producción: [https://www.formutech.com.co](https://www.formutech.com.co)  
Proyecto: `formutech-www` · GitHub: `dacaroqui/Formutech`

Cada push a `main` despliega ese mismo proyecto. No crear otro proyecto en Vercel para publicar cambios.

## Cómo correrlo en local

```bash
npm install
npm run dev
```

Abra [http://127.0.0.1:4317](http://127.0.0.1:4317).

```bash
npm run build
npm start
```

## Qué hay en el sitio

- Inicio con giro a pantalla completa (mitad operación industrial, mitad Oil & Gas)
- Soluciones con pestañas Industrial / Oil & Gas y buscador de referencias
- Familias industriales (hidráulico, metalworking, textil, anticorrosivo, dieléctrico, MW-70)
- Selector de viscosidad FormuLub ISO 32 / 46 / 68 / 100 con datos de ficha técnica
- Especialidades Oil & Gas con ficha de cada referencia
- Método en el inicio, diagnóstico de operación y Sobre FormuTech
- CTA *Hablemos de tu operación* por WhatsApp

## Datos técnicos

Las especificaciones publicadas salen de las fichas técnicas de FormuTech. Los aceites hidráulicos se presentan bajo normas DIN, ASTM, ISO y OEM, según indicación comercial de FormuTech.

El logo usado es el lockup oficial de FormuTech (símbolo + wordmark + tagline), sin redibujar el símbolo.
